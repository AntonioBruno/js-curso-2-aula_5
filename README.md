# 🎮 Jogo do Número Secreto

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante o curso de **Lógica de Programação com JavaScript**, oferecido pela plataforma **Alura**, com o objetivo de praticar conceitos fundamentais de programação e desenvolvimento web.

A aplicação consiste em um jogo interativo no qual o usuário deve descobrir um número secreto gerado aleatoriamente entre 1 e 10. A cada tentativa, o sistema fornece dicas para auxiliar o jogador até encontrar a resposta correta.

O projeto utiliza HTML, CSS e JavaScript, proporcionando uma experiência prática com lógica de programação, manipulação de elementos HTML e interação com o usuário.

## 🚀 Funcionalidades

- Geração aleatória de números entre 1 e 10.
- Verificação das tentativas realizadas pelo jogador.
- Exibição de dicas indicando se o número secreto é maior ou menor que o valor informado.
- Contabilização das tentativas até encontrar o número correto.
- Reinicialização do jogo sem necessidade de atualizar a página.
- Controle dos números sorteados para evitar repetições até completar a sequência de 10 números.
- Reprodução de mensagens por voz utilizando a biblioteca ResponsiveVoice.
- Interface visual com adaptação para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização, organização visual e responsividade.
- **JavaScript:** implementação da lógica do jogo e interatividade.
- **ResponsiveVoice:** reprodução de mensagens por voz.
- **Git e GitHub:** versionamento e armazenamento do projeto.

## 📚 Conhecimentos desenvolvidos

Durante o desenvolvimento, foram praticados conceitos importantes de JavaScript, incluindo:

- Declaração e manipulação de variáveis.
- Criação e utilização de funções.
- Estruturas condicionais (`if` e `else`).
- Operadores lógicos e de comparação.
- Manipulação do DOM com `document.querySelector()`.
- Utilização de arrays para armazenar informações.
- Geração de números aleatórios com `Math.random()`.
- Implementação de lógica para evitar números repetidos.
- Interação com eventos de botões.
- Organização e reutilização de código.

## ▶️ Como executar

1. Faça o download ou clone o repositório.
2. Mantenha os arquivos HTML, CSS, JavaScript e a pasta de imagens na estrutura original.
3. Abra o arquivo `index.html` em um navegador.
4. Digite um número entre 1 e 10 e clique em **Chutar**.
5. Utilize as dicas apresentadas até descobrir o número secreto.
6. Clique em **Novo jogo** para iniciar uma nova partida.

## 🎯 Objetivo de aprendizagem

O principal objetivo deste projeto foi consolidar os fundamentos da lógica de programação utilizando JavaScript, compreendendo como transformar regras e condições em funcionalidades interativas.

O desenvolvimento faz parte da minha jornada de aprendizado em Engenharia de Software, com foco na construção de uma base sólida em programação e no desenvolvimento progressivo de aplicações web.
